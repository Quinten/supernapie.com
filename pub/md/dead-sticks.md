## the engine failed

**'dead sticks' is an abstract and minimalisitc puzzle game with physics based on verlet integration.**

I wanted to make a simple and abstract puzzle game after playing the mobile game Minimize. So i started this prototype based on verlet integration. After developing the game mechanic i found out the game play felt a lot like Cut the Rope, so i abandoned the idea for while, but later i wanted to finish the title screens.

Anyway if you think the idea is still okay let me know and maybe i will make some more levels.

'dead sticks' comes from 'dead stick landing' which means landing an aircraft when the engine broke down.
